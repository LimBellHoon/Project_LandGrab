## 땅따먹기 로그라이트 — 스펙 §4.1 / §6 / §7 (확정판)

### §6. 수치 계산식 및 상한

#### §6.1 플레이어 이동속도
상한은 "카드·영웅으로 얻은 증가분 합계"에만 적용합니다. 슬로우·상태 배율은 상한 계산에서 제외합니다.

```
BASE_SPEED = 6.0                        // 칸/초, 고정 상수

B  = clamp( Σ(카드·영웅 이동속도 증가율), 0.0, +1.00 )   // ← +100% 상한은 여기에만
D  = Π(1 - slow_i)                       // 적·장판 등 감속 효과, 곱연산
D  = max(D, 0.30)                        // 감속 하한 (완전 정지 방지)
S  = 상태 배율                            // 아래 표, 상한 미적용

playerSpeed = BASE_SPEED × (1 + B) × D × S
```

| 상태 | S 값 | 비고 |
|---|---|---|
| 일반 이동 / 선 긋기 | 1.00 | |
| 안전 귀환 중 | 0.80 | M04 보유 시 1.50으로 대체 |
| M04 불굴의 돌진 중 | 1.50 | 상한 미적용 (상태 배율) |
| K08 회전 돌파 중 | 1.20 | 상한 미적용 |

주의: B에 합산되는 카드는 M01·M02·M06·M07(소형)·G07·F01뿐입니다. M04·K08의 속도 변화는 B가 아니라 S로 처리하세요. 그래서 "속도 카드를 다 모아 상한에 걸린 상태"에서도 돌진·회전의 속도감은 그대로 유지됩니다.

#### §6.2 불(도화선) 전파 속도
플레이어의 현재 속도가 아니라 BASE_SPEED를 기준으로 계산합니다. 속도 버프로 불을 느리게 만들 수 없게 하기 위한 규정입니다.

```
fuseMul = stageFuseMul + Σ(카드 불 전파 보정)    // F03 음수, F07 양수, G07 음수
fuseMul = clamp(fuseMul, 0.40, 1.50)
fuseSpeed = BASE_SPEED × fuseMul

// 예) 스테이지4(0.72) + F03 Lv1(-0.30) + F07 Lv1(+0.25) = 0.67 → 4.02 칸/초
```

| 항목 | 값 |
|---|---|
| fuseMul 하한 | 0.40 |
| fuseMul 상한 | 1.50 |
| 최소 유예 거리 | 발화 시 플레이어와 불 사이 2.0초 거리 강제 확보 |
| 전파 방향 | 발화 칸에서 내 땅 쪽(퇴로) 부터 플레이어 방향으로 |

#### §6.3 그로기 · 기절 내성

```
requiredGroggy(n) = stageGroggyTotal × (1 + 0.25 × n)      // n = 이번 판 누적 기절 횟수
if n >= 5:
    requiredGroggy(n) = stageGroggyTotal × (1 + 0.25 × 5 + 1.00 × (n - 5))

자연 감소 = stageGroggyTotal × 0.02 / 초
기절 해제 시 현재 게이지 = 0
```

그로기 획득량에는 상한이 없습니다. 내성 누적이 상한 역할을 합니다.

#### §6.5 배타 카드 — 전체 목록
하드 배타는 단 한 쌍입니다.

| 쌍 | 규칙 |
|---|---|
| M04 불굴의 돌진 ↔ K08 빙글빙글 | 둘 다 안전 귀환 버튼의 동작을 덮어쓰므로 공존 불가. 한쪽을 보유하면 다른 쪽을 뽑기 풀에서 완전 제외 (weight = 0) |

그 외에는 배타가 아니라 뽑기 가중치 조정입니다. 보유 자체는 가능하되 등장 확률만 낮춥니다.

| 조건 | 대상 | 가중치 배율 |
|---|---|---|
| F계열(F01~F07) 보유 수 ≥ 2 | G08 | ×0.1 |
| G08 보유 (Lv.1~2) | F01~F07 각각 | ×0.3 |
| G08 Lv.3 보유 | F01~F07 각각 | ×0.0 (완전 제외) |
| {G01, F03, F05} 중 2장 보유 | 남은 1장 | ×0.1 |
| K03 또는 K04 중 1장 보유 | 나머지 1장 | ×0.5 |

"G08 관련 확률 조정"의 뜻: G08(불강금선)은 도화선을 굴절로 대체하는 카드입니다. Lv.3에서 굴절 확률이 100%가 되면 도화선이 아예 발생하지 않아 F계열 7장이 전부 죽은 카드가 됩니다. 그래서 두 방향으로 막습니다.

- F계열을 이미 2장 이상 들었으면 G08이 거의 안 나오게 합니다.
- G08을 먼저 들었으면 F계열이 잘 안 나오게 하고, Lv.3에서는 F계열을 풀에서 완전히 빼버립니다.

즉 유저가 "굴절 빌드"와 "도화선 빌드" 중 한쪽을 자연스럽게 타게 되는 장치입니다. 카드 간 상성 로직이 아니라 뽑기 풀 필터로 구현하세요.

#### §7.2 밸런싱 기준 감각 (검수용)
- K02(경계선 충격파) Lv.1만 보유 → 그로기 +10/닫기. 스테이지 2(총량 60)에서 6회 닫아야 1회 기절.
- 제어 카드 3장 이상 보유 → 판당 3~4회 기절이 목표치.
- 제어 카드 0장 보유 → 판당 0~1회 기절. 이 경우에도 기동·수호 카드로 클리어가 가능해야 정상입니다.

### §4.1 카드 뽑기 알고리즘

```
function drawChoices(pickIndex, stage, ownedCards):
    // 1) 첫 선택은 고정 풀
    if pickIndex == 0:
        return ["K01", "M01", "G01"]        // 감전 선 / 스프린터 / 소화기

    // 2) 후보 필터
    maxTier = stage <= 3 ? 1 : (stage <= 6 ? 2 : 3)
    pool = allCards.filter(c =>
        c.tier <= maxTier
        and level(c) < 3
        and not isHardExcluded(c, ownedCards)   // §6.5 M04↔K08
    )

    // 3) 가중치 계산
    for c in pool:
        w = 1.0
        if isOwnedFamily(c.family, ownedCards): w *= 2.5      // 보유 계열 가중
        w *= weightModifier(c, ownedCards)                    // §6.5 확률 조정표
        c.weight = w

    // 4) 3장 추출 — 보유 계열 1장 이상 보장
    result = []
    if hasAnyOwnedFamily(ownedCards):
        result.add( weightedPick(pool.filter(c => isOwnedFamily(c.family))) )
    while result.size < 3:
        result.add( weightedPick(pool.exclude(result)) )

    return result
```

| 항목 | 값 |
|---|---|
| 보유 계열 가중치 | ×2.5 |
| 미보유 계열 가중치 | ×1.0 |
| 보유 계열 최소 보장 | 3장 중 1장 |
| 중복 카드 | 재선택 시 Lv +1 (Lv.3에서 풀 제외) |
| 리롤 | 판당 1회 무료. 리롤은 drawChoices를 동일 조건으로 재실행 |
| 코어 카드(K01/M01/G01) | 첫 선택 이후에도 일반 가중치로 계속 등장 |

보유 계열 최소 보장이 중요합니다. 완전 무작위면 7장이 4계열로 흩어져 시너지가 전혀 터지지 않고, "조금씩 세진 느낌"만 남아 재플레이 동기가 사라집니다.

### §5.1 안전 귀환 미구현 상태에서의 처리 (K08 / M04)
안전 귀환 버튼(§1)이 아직 없다면 두 카드는 발동할 훅이 없습니다. 아래 중 하나로 처리하세요.

| 방안 | 내용 |
|---|---|
| 권장 | 안전 귀환 버튼을 먼저 구현. §10 구현 순서의 2번 항목이며 K08·M04뿐 아니라 미리보기 UI, 도화선 탈출 동선까지 여기에 걸려 있습니다 |
| 임시 | 두 카드를 enabled: false로 두고 뽑기 풀에서 제외. 데이터만 유지 |

절대 하지 말아야 할 것: 귀환 버튼 없이 K08·M04를 별도 버튼으로 만드는 것입니다. 버튼이 3개가 되면 한 손가락 조작 설계가 무너집니다(§1 참조).
